# 🩺 Diabetes Prediction using Machine Learning

## 📌 Project Overview
This project predicts whether a person is diabetic using Machine Learning. The model is trained on the Pima Indians Diabetes Dataset using a Decision Tree Classifier.

---

## 🚀 Features
- Predicts diabetes based on health parameters
- Data preprocessing and feature scaling
- Decision Tree Classification model
- Trained model saved using Pickle

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
- Pickle

---

## 📂 Files

- Diabetes_Prediction.ipynb
- diabetes.csv
- diabetes_model.pkl
- scaler.pkl

---

## 📊 Machine Learning Model

- Decision Tree Classifier

---

## 📈 Dataset Features

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age
